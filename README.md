# NavBot – Autonomous Mobile Robot Navigation with ROS 2

## Overview

NavBot is a robotics project focused on autonomous navigation of mobile robots using the ROS 2 ecosystem.

The project explores the implementation and configuration of an autonomous navigation system using the TurtleBot3 platform and the Navigation2 (Nav2) framework. The robot uses sensor data, particularly LiDAR, to perceive its surroundings, estimate its position, plan navigation paths, and avoid obstacles while moving towards predefined goals.

The system integrates several ROS 2 components, including localization, mapping, costmaps, path planning, motion control, and obstacle avoidance.

## Technologies

- **ROS 2 Jazzy** – Robotics middleware and communication framework.
- **Navigation2 (Nav2)** – Autonomous navigation framework.
- **TurtleBot3** – Mobile robot platform.
- **Gazebo Harmonic** – Robot simulation environment.
- **RViz2** – Robot visualization and navigation interface.
- **LiDAR** – Environmental perception and obstacle detection.

## Project Objectives

- Understand and configure the ROS 2 navigation architecture.
- Explore the integration between sensors, localization, and navigation.
- Implement autonomous goal-based navigation.
- Investigate path planning and obstacle avoidance.
- Understand how different ROS 2 nodes communicate and coordinate to control a mobile robot.
